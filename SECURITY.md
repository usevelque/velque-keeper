# Security

Velque runs on Solana devnet with test tokens and has not been audited.

Report a vulnerability privately through the [velque-program](https://github.com/usevelque/velque-program/security/advisories/new) repository: its Security tab, "Report a vulnerability". Please do not open a public issue for anything that could move funds, block a market or put bad data on chain.

The full policy, with what is in scope and what is a known limit, is in [velque-program/SECURITY.md](https://github.com/usevelque/velque-program/blob/main/SECURITY.md).
